create_collection_decoder
#

cell_helpers.ts view source

(clear: () => void, add: (json: any) => unknown): (value: unknown) => typeof HANDLED import {create_collection_decoder} from '@fuzdev/zzz/cell_helpers.js';

Creates the decoder for a property that holds a collection of cells. An array value replaces the collection's contents — clear, then add for each element — and any other value leaves the collection unchanged. It always returns HANDLED, so the property is never assigned the raw JSON.

clear

empties the collection, disposing the items it owns

type () => void

add
