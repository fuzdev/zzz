Diskfile part - references content from a Diskfile.

inheritance

type "diskfile"

readonly

diskfile

The diskfile at path. One deleted on disk counts as missing unless it has a draft — then it's kept for the draft (see Diskfiles.remove_by_path), which the part shows and sends.

type Diskfile | null | undefined

readonly $derived.by

draft_status

How content relates to the disk: 'unsaved' when it's the file's draft, 'conflict' when that draft predates a change on disk, 'deleted' when the file is gone from disk and only the draft remains, else null (the disk content).

type "unsaved" | "conflict" | "deleted" | null

readonly $derived.by

Writable value that determines this.diskfile. Also includes special diskfile part logic for attributes.

type DiskfilePath | null

gettersetter

content

The file's draft if it has one (draft_status says so), else its disk content — never merely an older history entry an editor is viewing. Read-only: the part never writes to disk. Edits go through the file's DiskfileEditorState, whose save_changes reports failures.

undefined when there's no file at path, null when the file's content wasn't loaded (Diskfile.content_loaded) — never an editor's empty text, so an unloaded file can't pass for an empty one.

type string | null | undefined
