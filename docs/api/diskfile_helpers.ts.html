parse_new_diskfile_name
#

diskfile_helpers.ts view source

(name: string, kind: "file" | "folder"): Result<{ value: string; }, { message: string; }> import {parse_new_diskfile_name} from '@fuzdev/zzz/diskfile_helpers.js';

Parses a name entered for a new file or folder, a path relative to Diskfiles.new_files_dir (sub/name.ts creates any missing folders). Leading whitespace and slashes are dropped, as is trailing whitespace — like a pasted name's stray space or newline, they're almost never meant. Whitespace inside the name is kept, including around an inner /. Empty, ., and .. segments are left for the backend to normalize (sub/../a.txt creates a.txt). Refused: a blank or whitespace-only name; one that normalizes to the directory itself (sub/..); a whitespace-only segment (it would create a folder named by whitespace); a .. that climbs out of the directory; and for a file, a last segment that's empty, ., or .. (x/, x/., x/y/..), which names a folder, not a file.

name

the entered name

type string

kind

whether the name is for a file or a folder

type "file" | "folder"

returns

Result

the name to create, or a message saying why it's refused
